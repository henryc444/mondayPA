Privacy Policy

Monday — Personal Assistant · Last updated 20 September 2026

Who this covers

Monday is a private assistant used by exactly one person — its owner — on a server the owner controls. There are no other users, and no service is offered to the public. This policy describes how it handles Google account data.

What Google data is accessed

  • Gmail — read messages, apply and remove labels, archive messages, and create filters and settings. This is the only Google service used on an ongoing basis.
  • Google Calendar, Drive, Sheets and Docs — accessed only when the owner explicitly requests a specific action. No automated collection takes place.
  • Contacts — read-only, and only when the owner requests it.

How that data is used

Solely to organise the owner's own mailbox: sorting messages into labels, moving clutter out of the inbox, and creating filters so future mail is sorted automatically. Data is used for no other purpose.

Where data is stored

  • Email content remains in the owner's Google account. It is not copied to any other system in bulk.
  • OAuth access and refresh tokens are stored as a local file on the owner's own server, readable only by the owner's account (file mode 600).
  • Operational notes are written to a private, local, plain-text journal on the same server.
  • No cloud database, and no third-party analytics or advertising service, is involved.

Sharing

None. Google data is never sold, rented, shared, transferred or published to any third party, and is never used for advertising, profiling, or training machine-learning models.

Retention

Authorisation persists until the owner revokes it. Deleting the token file on the owner's server removes the stored credentials immediately.

Your control — revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revocation takes effect immediately; the assistant loses all access to the account.

Limited Use disclosure

This application's use of Google user data is limited to providing the single-user mailbox organisation function described above. It complies with the Google API Services User Data Policy, including the Limited Use requirements.
