Monday — Personal Assistant

A single-user personal automation tool.

What this application is

Monday is a private, single-user assistant that runs on its owner's own server. It is not a public product and it has no other users. Its Google integration exists so the assistant can organise the owner's own mailbox — sorting mail into labels, archiving clutter, and creating filters — instead of the owner doing it by hand.

What it does with Google data

  • Reads the owner's own Gmail messages in order to classify them.
  • Applies and removes Gmail labels, and archives messages.
  • Creates Gmail filters so that future mail is sorted automatically.
  • Accesses Google Calendar, Drive, Sheets and Docs only when the owner explicitly asks it to.

What it does not do

  • It does not send email on the owner's behalf without an explicit instruction each time.
  • It does not delete mail, and it does not share, sell or publish any Google data.
  • It does not serve other people, and it does not operate as a hosted service.
